# Banking Transaction Analysis Using Python

## Overview
This project explores synthetic banking transaction data using Python to practise data cleaning, exploratory data analysis, and extracting insights from financial transaction records.

## Tools & Technologies
- Python
- Pandas
- NumPy
- Google Colab

## Dataset
The dataset contains 1,000 simulated banking transactions, including transaction IDs, customer IDs, dates, categories, amounts, and payment methods.

All data is synthetic and created for educational and portfolio purposes.

## Work Completed
- Generated a synthetic transaction dataset.
- Inspected dataset dimensions, data types, and statistical summaries.
- Identified missing values and duplicate records.
- Introduced data-quality issues to simulate a real-world cleaning exercise.
- Removed duplicate records.
- Imputed missing transaction amounts using the median.

## Project Status
In progress - transaction analysis, customer spending patterns, visualisations, and business insights are being developed.

## Objectives
- Explore transaction patterns.
- Analyse spending by category.
- Identify high-value customers.
- Examine transaction trends over time.
- Detect unusually large transactions.
- Communicate findings through visualisations.
